# Selectable Subtitles for YouTube — Privacy Policy

_Last updated: November 18, 2026_

Selectable Subtitles for YouTube is a Chrome extension that shows YouTube subtitles as selectable text.

## Data collection

The extension does not collect, store, transmit, sell or share any personal data or browsing data. It has no analytics, no tracking, no accounts and no remote servers.

## Data stored on your device

The extension saves its own settings (text size, background opacity, the "hold phrase during pauses" option and the position of the subtitle box) using Chrome's local extension storage (`chrome.storage.local`). This data stays on your computer and is removed when you uninstall the extension.

## Page access

The extension runs only on `https://www.youtube.com/`. It reads the subtitle text that the YouTube player loads, only to display it on screen. This text is not saved or sent anywhere.

## Third parties

The extension does not send data to any third party. If you use other extensions on the selected text (for example, a dictionary), their own privacy policies apply.

## Open source

The full source code of the extension is available in this repository, so anyone can check what it does.
